# Artisan Connect

A Vite+React app for connecting customers with skilled workers/artisans.

## Running the app

```bash
npm install
npm run dev
```

## Building the app

```bash
npm run build
```

## Features

- Browse and search for workers by category, location, and skills
- Request quotes from workers
- Manage job requests and quotes
- Messaging system
- User dashboard and settings

Note: This app uses dummy data for demonstration purposes.
